# VecFlow Image Language 🌟
**Founder:** Isaiah Micheal Asuquo

VecFlow is a Domain-Specific Language (DSL) for image processing, drawing, and AI generation. Built from scratch in Python.

## 🚀 Features
- **AI Image Generation:** Generate real photos from text prompts.
- **Photoshop Filters:** Blur, Sharpen, Edges, Invert, Sepia, Cartoon.
- **Drawing:** Canvas, Rectangles, Circles, Lines, Custom Text.
- **Math & Logic:** Hex Colors, Variables, Blending, Cropping.
